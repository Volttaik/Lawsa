# Sosa

A modern social networking platform built with Next.js, Tailwind CSS, and Turso.

## Environment Variables / Secrets

Set these in Replit Secrets:

- `TURSO_DATABASE_URL`
- `TURSO_AUTH_TOKEN`
- `JWT_SECRET`

## Notes

- Turso is the primary database.
- Social actions, profile edits, posts, messages, notifications, clans, and stories should all persist to Turso.
- The app runs with `npm run dev`.
